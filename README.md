# Sara Magalhães — Portfólio

Portfólio pessoal e acadêmico desenvolvido com **Next.js 14**, **TypeScript** e **Tailwind CSS**, combinando estilo de terminal e referências visuais ao Studio Ghibli.

**Site:** [sara-portfolio-nine-zeta.vercel.app](https://sara-portfolio-nine-zeta.vercel.app/)

## Destaques

- **Bilingue (PT-BR / EN):** Alternância completa de idioma e currículo correspondente.
- **Terminal Interativo:** Mock de requisições de API no Hero.
- **Projetos e Artigos:** Destaque para pesquisa em Edge AI (YOLO) na UFC e projetos reais (ERP LESC, Assidui, EcoCiclo, MonitoraME).
- **Formulário com Envio Real:** Integrado ao Resend.

## Tecnologias

Next.js 14, TypeScript, Tailwind CSS, Resend.

## Execução Local

```bash
git clone https://github.com/SaraMag25/sara-portfolio.git
cd sara-portfolio
npm install
cp .env.example .env.local # preencha RESEND_API_KEY e CONTACT_TO_EMAIL
npm run dev
```
